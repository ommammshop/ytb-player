# YTB Player (ฉบับภาษาไทย)

ส่วนที่เพิ่มในฉบับนี้: เมนูภาษาไทย, คีย์บอร์ดไทย และช่องโปรดแบบไม่ต้องเข้าสู่ระบบ

## ติดตั้ง

1. ก๊อป `ytb-player.nro` ไปไว้ที่ `sdmc:/switch/ytb-player/ytb-player.nro`
2. เปิดจาก HBMenu หรือ forwarder บนหน้า Home

## เปลี่ยนเป็นภาษาไทย

1. เข้าแท็บ **Settings** (ไอคอนเฟือง)
2. เลือก **Language** แล้วเลือก **ภาษาไทย**
3. ออกจากแอปแล้วเปิดใหม่ เมนูทั้งหมดจะเป็นภาษาไทย และหน้าแรก / Trending จะเป็นของประเทศไทย

## คีย์บอร์ดไทย

กดช่องค้นหา (หรือกด X ในแท็บค้นหา) จะขึ้นคีย์บอร์ดผังเกษมณี

| ปุ่ม | ทำอะไร |
|---|---|
| ปุ่มทิศ / แตะจอ + A | พิมพ์ตัวอักษร |
| B (กดค้างได้) | ลบ |
| Y | เว้นวรรค |
| X | Shift (ใช้ได้ 1 ตัวอักษรแล้วปล่อยเอง) |
| L | สลับ ไทย / ABC |
| + | ค้นหา |
| - | ปิดคีย์บอร์ด |

## ช่องโปรด (ไม่ต้องเข้าสู่ระบบ)

### เพิ่มช่อง
1. หาคลิปของช่องที่ต้องการ (ค้นหาชื่อช่องหรือชื่อคลิป)
2. เลื่อนไปที่คลิปนั้นแล้วกด **Y** เพื่อเปิดหน้าข้อมูลคลิป
3. กด **X** (ช่อง) เพื่อเปิดหน้าของช่อง
4. กดปุ่ม **☆ เพิ่มช่องโปรด** ใต้ชื่อช่อง หรือกด **X** บนหน้าช่อง
   ปุ่มจะเปลี่ยนเป็น **★ อยู่ในช่องโปรด**

### ดูคลิปจากช่องโปรด
- เข้าแท็บ **ช่องที่ติดตาม** จะเห็นคลิปใหม่จากทุกช่องโปรด เรียงจากใหม่ไปเก่า
- แถวรูปวงกลมด้านบนคือช่องต่าง ๆ กดเพื่อเปิดหน้าช่อง
- **L / R** เปลี่ยนตัวกรอง (ทั้งหมด / วันนี้ / วิดีโอ / ไลฟ์ / Shorts)
- **X** รีเฟรช

### เอาช่องออก
เปิดหน้าช่องนั้นแล้วกดปุ่ม **★ อยู่ในช่องโปรด** (หรือ **X**) อีกครั้ง

### ข้อควรรู้
- รายการช่องโปรดเก็บไว้ใน SD ที่ไฟล์ `library.json` ของแอป ใช้ได้โดยไม่ต้องมีบัญชี Google
- ถ้าเข้าสู่ระบบบัญชี YouTube แท็บ **ช่องที่ติดตาม** จะแสดงช่องที่บัญชีนั้นติดตามแทน
- ช่องโปรดจำนวนมากจะโหลดนานขึ้น เพราะแอปดึงคลิปจากทีละช่อง (แสดงสูงสุด 40 ช่อง ช่องละ 8 คลิปล่าสุด)
